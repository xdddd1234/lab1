# Промпт 02 — ER-модель

Я виконую лабораторну роботу з моделювання домену та ER-моделі даних.

На основі специфікації проєкту Library Management System побудуй ER-модель у синтаксисі Mermaid `erDiagram`.

Модель повинна містити сутності:
- Reader
- Book
- Author
- Category
- Loan

Для кожної сутності вкажи атрибути та первинні ключі (PK). Для зв'язків, де це необхідно, вкажи зовнішні ключі (FK).

Використовуй однаковий тип для всіх ідентифікаторів.

Покажи кардинальності всіх зв'язків відповідно до специфікації.

Зв'язок між Author і Book повинен бути many-to-many без створення окремої сполучної сутності.

Loan повинен бути окремою сутністю, оскільки факт видачі книги має власні атрибути.

Не використовуй SQL DDL або ORM. Результатом має бути декларативна ER-модель у Mermaid.
