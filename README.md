# Library Management System

Library Management System — це навчальний проєкт для моделювання предметної області бібліотеки.

Система описує основні сутності бібліотеки: читачів, книги, авторів, категорії та видачі книг. Мета проєкту — побудувати нормалізовану ER-модель із коректними атрибутами, ключами, зв'язками та кардинальностями.

Репозиторій містить специфікацію предметної області, ER-модель, ADR-рішення, історію використання AI та матеріали для захисту.
